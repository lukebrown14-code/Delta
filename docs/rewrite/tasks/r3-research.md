# R3.2 — Research + reports

The core product loop: gather evidence, generate a cited report, read it.

- **Branch:** `rewrite/r3-research`
- **Runs:** parallel, after R3.1
- **Findings:** `docs/rewrite/findings/rust-services.md` (reports), `rust-screens.md` (screen)

## Owns

`crates/delta-services/src/reports.rs`, `crates/delta-tui/src/screens/research.rs`,
`tests/golden_scenarios/research.py`.

## Python sources

`delta/reports.py` (`build_report`, `render_markdown`, claim filtering against
gathered ids), `delta/tui/screens/research.py`, `research_state.py`,
`research_viewer.py`, `reports.py`, `data.py`; prompt `report_v2.j2` (already
verbatim). Python tests: `test_reports.py`, `test_research.py`.

## Work

- `reports.rs`: build, claim filter, markdown render, write `reports/<target>/<date>.md`
  and its sidecar. Same filename and sidecar format as Python.
- Screen bindings as Python: `e` evidence, `r` report, `n` generate, `u`
  update evidence, `U` gather all, `/` search, `k` kind, `l` load more, `space`
  fold prices, `t` targets, `o` open source, `v` view in report, `z` zoom, `esc`.
- Citations sidebar, sentiment stance, quote stream.

## Provenance (never weaken)

Claims cite gathered evidence ids only; an invalid result fails. Any doubt: log and stop.

## Golden scenarios

Populated report, no report, generating, evidence pane (each kind), search
active, citation selected, zoomed, error (LLM failure).
