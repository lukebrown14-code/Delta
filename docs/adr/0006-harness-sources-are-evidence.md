# Harness-found sources are stored as evidence

V1 never stored web results; they were a labelled, chat-only aid. In V2 the harness submits what it finds as **harness sources** (URL, extract, retrieval date), and Delta stores each one as evidence that can be cited like any other. Harness sources are text only. Numeric series (prices, fundamentals, macro) arrive only through data sources.

The citation contract requires every report paragraph to cite stored evidence. Without harness sources, the harness's own research could never be cited, and reports would be limited to what the data sources happened to fetch. Restricting harness sources to text keeps charts, readings and trade outcomes on repeatable, refreshable data. See [Space creation interview](https://github.com/lukebrown14-code/Delta/issues/61) and [Data sources in config](https://github.com/lukebrown14-code/Delta/issues/63).
