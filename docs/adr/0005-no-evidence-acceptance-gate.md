# No acceptance gate on evidence

V1 required the user to accept candidate evidence before it affected thesis health. V2 drops that gate. A Space automatically sees all evidence about its members, and other evidence is linked explicitly by the harness or the user. Only linked evidence can be removed, and a report that cites removed evidence is flagged until it is rewritten.

With a harness doing the research, an acceptance step on every item would make the user a bottleneck on their own tool. Provenance is still enforced at the point it matters: every report paragraph must cite stored evidence, and readings record exactly which evidence they were given. See [Space model](https://github.com/lukebrown14-code/Delta/issues/60).
